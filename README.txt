JESS ANSON MASCARENHAS — PORTFOLIO WEBSITE

HOW TO RUN
1. Extract this folder if you downloaded the ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. For the best developer workflow, open the folder in VS Code and use the Live Server extension.

CUSTOMIZE
- Edit index.html for text, projects, and links.
- Edit style.css for colors, layout, and typography.
- Edit script.js for menu and interaction behavior.

NOTES
- This is a static website; no build step is required.
- Google Fonts requires an internet connection; fallback fonts will be used otherwise.
- Project cards describe concepts and projects discussed so far. Add verified demos and screenshots as they become available.
- The GitHub profile and EV ChargeHub / Habit Tracker repository links use the profile/repo URLs previously shared.
- Contact section currently links to GitHub because no email address was confirmed for this site.
